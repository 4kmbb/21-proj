# Объяснение решения задания 3 (`src/quest3.c`)

## Что делает программа
Программа читает число `n` и выводит `n`-е число Фибоначчи, используя рекурсию.
При некорректном вводе выводит `n/a`.

## Функция `fibonacci_recursive(int n)`
Эта функция реализует классическое рекурсивное определение:
- `F(0) = 0`
- `F(1) = 1`
- `F(n) = F(n - 1) + F(n - 2)` для `n > 1`

Как работает:
1. если `n == 0`, возвращается `0`;
2. если `n == 1`, возвращается `1`;
3. иначе функция вызывает саму себя для `n - 1` и `n - 2` и складывает результаты.

## Почему тип `long long`
Даже при небольшом росте `n` значения Фибоначчи растут быстро.
Тип `int` переполняется значительно раньше, поэтому в функции и выводе используется `long long`.

## Главная функция `main()`
Что делает `main`:
- считывает `n` и следующий символ;
- проверяет, что ввод корректный (после числа сразу `\n`);
- проверяет, что `n >= 0`;
- печатает результат `fibonacci_recursive(n)`.

Если хотя бы одно условие нарушено, печатается `n/a`.

## Ограничения такого подхода
Рекурсивный способ простой и понятный для учебной задачи, но:
- делает много повторных вычислений;
- работает медленно на больших `n`.

Для этого задания выбран именно рекурсивный вариант, потому что это прямое требование условия.
