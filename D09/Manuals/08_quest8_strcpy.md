## 2. Что делает `strcpy`

`s21_strcpy(dest, src)` копирует строку `src` в буфер `dest` **вместе с
завершающим `'\0'`**.

Пример:

```c
char source[] = "hello";
char destination[20];

s21_strcpy(destination, source);

// теперь destination содержит "hello"
```

Схема:

```text
source:      'h' 'e' 'l' 'l' 'o' '\0'
destination: 'h' 'e' 'l' 'l' 'o' '\0' ...
```

Функция возвращает указатель на начало `dest`. Это позволяет писать
цепочки вызовов, как у стандартной `strcpy`.

## 3. Главное правило безопасности

`dest` должен быть достаточно большим. `s21_strcpy` не знает размер
буфера и не проверяет его. Если в `dest` меньше места, чем в `src`,
произойдёт переполнение буфера — это неопределённое поведение (UB).

Неправильно:

```c
char destination[3];
char source[] = "hello";
s21_strcpy(destination, source);  // переполнение!
```

Правильно:

```c
char destination[20];
char source[] = "hello";
s21_strcpy(destination, source);
```

## 4. Объявление в `s21_string.h`

```c
char* s21_strcpy(char* dest, const char* src);
```

| Элемент | Что означает |
|---|---|
| `char*` | Функция возвращает указатель на символ. |
| `s21_strcpy` | Имя функции. |
| `char* dest` | Буфер, куда копируем. Его содержимое меняется, поэтому `const` нет. |
| `const char* src` | Источник. Его мы только читаем, поэтому `const`. |
| `;` | Конец объявления. |

## 5. Реализация `s21_strcpy`

> Номера строк в таблице ниже считаются внутри показанного фрагмента.

```c
/*
 * Копируем строку src в dest вместе с завершающим '\0'.
 * Возвращаем указатель на начало dest — так делает стандартная strcpy.
 * Вызывающая сторона должна сама позаботиться о размере dest.
 */
char* s21_strcpy(char* dest, const char* src) {
    size_t i = 0;

    while (src[i] != '\0') {
        dest[i] = src[i];
        i++;
    }
    dest[i] = '\0';

    return dest;
}
```

### Разбор каждой строки

| Строка | Что написано | Что это значит |
|---|---|---|
| 1–5 | комментарий | Объясняет, что копируется `'\0'`, что возвращается `dest` и что размер буфера — ответственность вызывающего. |
| 6 | `char* s21_strcpy(char* dest, const char* src) {` | Начало функции. |
| 7 | `size_t i = 0;` | Индекс текущего символа. |
| 8 | пустая строка | Разделитель. |
| 9 | `while (src[i] != '\0') {` | Пока не дошли до конца источника... |
| 10 | `dest[i] = src[i];` | ...копируем очередной символ. |
| 11 | `i++;` | Переходим к следующему индексу. |
| 12 | `}` | Конец цикла. |
| 13 | `dest[i] = '\0';` | Вручную добавляем завершающий ноль. Цикл его не копирует, потому что останавливается на нём. |
| 14 | пустая строка | Разделитель. |
| 15 | `return dest;` | Возвращаем указатель на начало буфера. |
| 16 | `}` | Конец функции. |

### Почему недостаточно скопировать только символы

Если не добавить `'\0'`, строка в `dest` не будет корректно
завершена. Функции `s21_strlen`, `s21_strcmp`, `printf("%s")` будут
читать память дальше, пока случайно не найдут ноль. Это ошибка.

### Почему возвращается `dest`, а не `src`

Стандартная `strcpy` возвращает `dest`, чтобы результат можно было
использовать в выражении:

```c
printf("%s\n", s21_strcpy(destination, source));
```

Если вернуть `src`, это было бы несовместимо по смыслу со стандартной
функцией.

### Почему `dest` нельзя делать `const`

`const char* dest` означал бы «нельзя менять символы по этому адресу».
Но копирование как раз меняет `dest`, поэтому `const` там не ставится.
`src` мы только читаем, поэтому он `const`.

### Что будет, если строки пересекаются

Если `dest` и `src` указывают на перекрывающиеся области памяти,
поведение нашей функции может быть неправильным. Стандартная `strcpy`
для перекрывающихся областей тоже не предназначена — для этого есть
`memmove`. В учебной задаче такие случаи не рассматриваются.

## 6. Пример работы

```c
char source[] = "cat";
char destination[10];

s21_strcpy(destination, source);
```

Пошагово:

```text
i = 0: src[0] = 'c' != '\0' -> dest[0] = 'c', i = 1
i = 1: src[1] = 'a' != '\0' -> dest[1] = 'a', i = 2
i = 2: src[2] = 't' != '\0' -> dest[2] = 't', i = 3
i = 3: src[3] = '\0'         -> цикл закончился
dest[3] = '\0'
return dest
```

## 10. Типичные ошибки

### Маленький буфер

```c
char destination[3];
s21_strcpy(destination, "hello");  // переполнение
```

### Забыли `'\0'`

```c
while (src[i] != '\0') {
    dest[i] = src[i];
    i++;
}
// нет dest[i] = '\0';
```

После такого кода строка в `dest` не завершена.

### Перепутали порядок аргументов

```c
s21_strcpy(src, dest);  // пытаемся писать в const-строку
```

Компилятор может выдать ошибку, потому что `src` объявлен как
`const char*`, а функция ждёт `char*`.

### Использовали `strcpy` из `string.h`

По условию нельзя. Нужна своя реализация.
