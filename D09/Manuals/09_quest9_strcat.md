## 2. Что делает `strcat`

`s21_strcat(dest, src)` добавляет строку `src` в конец строки `dest`.

Пример:

```c
char text[30] = "hello";
char suffix[] = " world";

s21_strcat(text, suffix);

// text теперь содержит "hello world"
```

Схема:

```text
до:
dest: 'h' 'e' 'l' 'l' 'o' '\0' ...
src:  ' ' 'w' 'o' 'r' 'l' 'd' '\0'

после:
dest: 'h' 'e' 'l' 'l' 'o' ' ' 'w' 'o' 'r' 'l' 'd' '\0' ...
```

Функция возвращает указатель на начало `dest`, как стандартная `strcat`.

## 3. Главное правило безопасности

В `dest` должно хватать места для:

- старой строки `dest`;
- строки `src`;
- завершающего `'\0'`.

Неправильно:

```c
char text[8] = "hello";  // 5 символов + '\0', свободно 2 байта
s21_strcat(text, " world");  // нужно ещё 6 символов — переполнение
```

Правильно:

```c
char text[30] = "hello";
s21_strcat(text, " world");
```

## 4. Объявление в `s21_string.h`

```c
char* s21_strcat(char* dest, const char* src);
```

| Элемент | Что означает |
|---|---|
| `char*` | Возвращаем указатель на начало `dest`. |
| `s21_strcat` | Имя функции. |
| `char* dest` | Строка, в конец которой добавляем. Она меняется. |
| `const char* src` | Источник, который только читаем. |
| `;` | Конец объявления. |

## 5. Реализация `s21_strcat`

> Номера строк в таблице ниже считаются внутри показанного фрагмента.

```c
/*
 * Добавляем строку src в конец строки dest.
 * Сначала находим конец dest, потом копируем туда src.
 */
char* s21_strcat(char* dest, const char* src) {
    size_t dest_length = s21_strlen(dest);
    size_t i = 0;

    while (src[i] != '\0') {
        dest[dest_length + i] = src[i];
        i++;
    }
    dest[dest_length + i] = '\0';

    return dest;
}
```

### Разбор каждой строки

| Строка | Что написано | Что это значит |
|---|---|---|
| 1–4 | комментарий | Объясняет алгоритм: найти конец `dest`, затем копировать `src`. |
| 5 | `char* s21_strcat(char* dest, const char* src) {` | Начало функции. |
| 6 | `size_t dest_length = s21_strlen(dest);` | Находим длину уже существующей строки. Это индекс её `'\0'` — именно туда начнём писать. |
| 7 | `size_t i = 0;` | Индекс символа в `src`. |
| 8 | пустая строка | Разделитель. |
| 9 | `while (src[i] != '\0') {` | Идём по `src` до конца. |
| 10 | `dest[dest_length + i] = src[i];` | Записываем символ `src` в позицию после конца `dest`. |
| 11 | `i++;` | Следующий символ. |
| 12 | `}` | Конец цикла. |
| 13 | `dest[dest_length + i] = '\0';` | Добавляем завершающий ноль в конец новой строки. |
| 14 | пустая строка | Разделитель. |
| 15 | `return dest;` | Возвращаем начало `dest`. |
| 16 | `}` | Конец функции. |

### Почему используем `s21_strlen`

Нам нужно знать, где заканчивается `dest`. Можно было бы написать
свой цикл, но у нас уже есть `s21_strlen` из Quest 6. Повторное
использование кода — хорошая практика.

### Почему `dest_length + i`

Индекс в `dest` складывается из:

- `dest_length` — сколько символов уже было;
- `i` — сколько символов из `src` уже скопировали.

Пример:

```text
dest = "hello", dest_length = 5

i = 0: dest[5 + 0] = ' '
i = 1: dest[5 + 1] = 'w'
...
i = 5: dest[5 + 5] = 'd'
после цикла: dest[5 + 6] = '\0'
```

### Почему `dest[dest_length + i] = '\0'` в конце важен

Без него новая строка не будет завершена, и функции будут читать
«мусор» за её концом.

## 6. Пример пошагово

```c
char text[30] = "cat";
char suffix[] = "s";
s21_strcat(text, suffix);
```

```text
dest_length = 3
i = 0: text[3 + 0] = 's', i = 1
i = 1: src[1] = '\0' -> цикл закончился
text[3 + 1] = '\0'
результат: "cats"
```

Если `src` пустая:

```c
char empty[] = "";
s21_strcat(text, empty);
```

Цикл не выполнится ни разу, но `dest[dest_length] = '\0'` всё равно
запишется. Строка останется прежней — это корректно.

## 7. Почему в Quest 9 нет новой тестовой функции

В задании нет требования добавить `s21_strcat_test`. Примечание из
Quest 8 действует и дальше: тесты создаются только по прямому указанию.
Поэтому в `main` по-прежнему запускаются только `s21_strlen_test` и
`s21_strcmp_test`.

Проверить функцию можно временной программой:

```c
#include <stdio.h>

#include "s21_string.h"

int main(void) {
    char text[30] = "hello";
    char suffix[] = " world";

    s21_strcat(text, suffix);
    printf("%s\n", text);
    return 0;
}
```

Ожидаемый вывод:

```text
hello world
```

## 10. Типичные ошибки

### Маленький буфер

Самая частая ошибка. Нужно заранее посчитать, сколько места потребуется:

```text
strlen(dest) + strlen(src) + 1
```

Последняя единица — под `'\0'`.

### Забыли завершающий ноль

Без `dest[dest_length + i] = '\0'` строка не будет корректно
завершена.

### Неправильный стартовый индекс

Если начать писать с `dest[0]`, старая строка будет перезаписана,
а не дополнена. Нужно начинать с `dest_length`.

### Источник и приёмник — одна и та же строка

Случай `s21_strcat(text, text)` требует особой аккуратности: при
копировании можно затереть ещё не прочитанные символы. В учебной
задаче такой случай не рассматривается.

### Использовали `strcat` из `string.h`

Нельзя по условию. Нужна своя реализация.
