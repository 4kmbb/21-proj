## 2. Что делает `strchr`

`s21_strchr(str, c)` ищет символ `c` в строке `str`.

Возвращает:

- указатель на **первое** вхождение символа;
- `NULL`, если символ не найден.

Пример:

```c
char text[] = "hello";
char* p = s21_strchr(text, 'l');

// p указывает на первую 'l'
printf("%s\n", p);  // "llo"
```

Схема:

```text
text: 'h' 'e' 'l' 'l' 'o' '\0'
                ^
                p
```

## 3. Особый случай `c == '\0'`

Стандартная `strchr` умеет искать и завершающий ноль. Если передать
`'\0'`, функция должна вернуть указатель на конец строки — на тот самый
`'\0'`.

Пример:

```c
char text[] = "hello";
char* p = s21_strchr(text, '\0');

// p указывает на text[5] — завершающий ноль
```

Наша реализация это поддерживает.

## 4. Объявление в `s21_string.h`

```c
char* s21_strchr(const char* str, int c);
```

| Элемент | Что означает |
|---|---|
| `char*` | Возвращаем указатель на символ внутри строки или `NULL`. |
| `s21_strchr` | Имя функции. |
| `const char* str` | Строка для поиска. Мы её не меняем. |
| `int c` | Искомый символ. Тип `int`, как у стандартной функции: символ передаётся как число. |
| `;` | Конец объявления. |

### Почему `int c`, а не `char c`

Стандартная сигнатура `strchr` использует `int`, потому что символы в C
при передаче в функцию повышаются до `int`. Кроме того, `EOF` и другие
специальные значения тоже имеют тип `int`. Мы повторяем стандартную
сигнатуру.

## 5. Реализация `s21_strchr`

> Номера строк в таблице ниже считаются внутри показанного фрагмента.

```c
/*
 * Ищем символ c в строке str.
 * Если нашли — возвращаем указатель на первое вхождение.
 * Если не нашли — возвращаем NULL.
 * Отдельно обрабатываем c == '\0': тогда результатом будет указатель
 * на завершающий ноль в конце строки.
 */
char* s21_strchr(const char* str, int c) {
    char* result = NULL;
    size_t i = 0;

    while (result == NULL && str[i] != '\0') {
        if (str[i] == (char)c) {
            // Убираем const только потому, что прототип функции этого требует
            result = (char*)(str + i);
        }
        i++;
    }

    if (result == NULL && (char)c == '\0') {
        result = (char*)(str + i);
    }

    return result;
}
```

### Разбор каждой строки

| Строка | Что написано | Что это значит |
|---|---|---|
| 1–6 | комментарий | Объясняет поиск, `NULL` и особый случай `'\0'`. |
| 7 | `char* s21_strchr(const char* str, int c) {` | Начало функции. |
| 8 | `char* result = NULL;` | Пока ничего не нашли. `NULL` — специальный указатель «никуда». |
| 9 | `size_t i = 0;` | Индекс текущего символа. |
| 10 | пустая строка | Разделитель. |
| 11 | `while (result == NULL && str[i] != '\0') {` | Идём, пока не нашли символ и не дошли до конца строки. |
| 12 | `if (str[i] == (char)c) {` | Если текущий символ совпал с искомым... |
| 13 | комментарий | Поясняет приведение `const`. |
| 14 | `result = (char*)(str + i);` | ...запоминаем адрес этого символа. `str + i` — указатель на `i`-й символ. |
| 15 | `}` | Конец `if`. |
| 16 | `i++;` | Переходим к следующему символу. |
| 17 | `}` | Конец цикла. |
| 18 | пустая строка | Разделитель. |
| 19 | `if (result == NULL && (char)c == '\0') {` | Если ничего не нашли, но искали именно `'\0'`... |
| 20 | `result = (char*)(str + i);` | ...возвращаем указатель на завершающий ноль. После цикла `i` как раз равен длине строки. |
| 21 | `}` | Конец `if`. |
| 22 | пустая строка | Разделитель. |
| 23 | `return result;` | Возвращаем найденный указатель или `NULL`. |
| 24 | `}` | Конец функции. |

### Что такое `str + i`

`str` — указатель на первый символ. `str + i` — указатель на символ с
индексом `i`. Это указательная арифметика:

```text
str + 0 -> 'h'
str + 1 -> 'e'
str + 2 -> 'l'
str + 3 -> 'l'
str + 4 -> 'o'
str + 5 -> '\0'
```

### Почему `(char*)`, если строка `const`

Параметр `str` имеет тип `const char*`: мы обещали не менять строку.
Но прототип функции возвращает обычный `char*`, как стандартная
`strchr`. Приходится явно убирать `const` приведением `(char*)`.

Это не значит, что мы собираемся менять символ. Мы лишь возвращаем
адрес. Главное — не писать по этому адресу в функциях, которые
обещают не менять строку.

### Почему цикл останавливается на `'\0'`

Мы не хотим читать память за пределами строки. Условие
`str[i] != '\0'` гарантирует, что цикл завершится на завершающем нуле.

### Почему проверка `c == '\0'` стоит после цикла

Цикл специально не заходит на `'\0'`. Поэтому случай `c == '\0'`
обрабатывается отдельно: после цикла `i` указывает ровно на
завершающий ноль, и мы возвращаем этот адрес.

## 6. Примеры работы

### Пример 1: символ найден

```c
char text[] = "hello";
char* p = s21_strchr(text, 'l');
printf("%s\n", p);
```

```text
p -> первая 'l'
вывод: "llo"
```

### Пример 2: символ не найден

```c
char text[] = "hello";
char* p = s21_strchr(text, 'z');
```

```text
p == NULL
```

### Пример 3: ищем завершающий ноль

```c
char text[] = "hello";
char* p = s21_strchr(text, '\0');
printf("offset = %ld\n", (long)(p - text));
```

```text
offset = 5
```

### Пример 4: пустая строка

```c
char text[] = "";
char* p = s21_strchr(text, '\0');
```

```text
p указывает на text[0] — завершающий ноль пустой строки
```

## 10. Типичные ошибки

### Разыменование `NULL`

```c
char* p = s21_strchr(text, 'z');
printf("%s", p);  // ошибка: p == NULL
```

Перед использованием результата нужно проверить указатель:

```c
if (p != NULL) {
    printf("%s\n", p);
}
```

### Сравнение `char` и `int` без приведения

Мы приводим `c` к `char`:

```c
str[i] == (char)c
```

Это делает сравнение предсказуемым.

### Забыли случай `c == '\0'`

Если не обработать его отдельно, функция вернёт `NULL` вместо указателя
на конец строки.

### Выход за границу строки

Если убрать проверку `str[i] != '\0'`, цикл будет читать память за
пределами массива. Это UB.

### Использовали `strchr` из `string.h`

Нельзя по условию. Нужна своя реализация.
