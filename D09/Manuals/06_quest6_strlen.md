## 2. Что такое строка в C

В C строки — это не отдельный тип, а массив символов `char`, который
заканчивается специальным символом `'\0'` (нулевой байт).

Например:

```c
char text[] = "hello";
```

В памяти лежит:

```text
'h' 'e' 'l' 'l' 'o' '\0'
```

`'\0'` — это не символ `'0'`, а именно байт со значением `0`. Он
показывает функциям, где заканчивается строка.

Длина строки `"hello"` — `5`, потому что `'\0'` не считается.

## 3. Что такое `size_t`

`size_t` — беззнаковый целый тип для размеров и индексов. Именно его
возвращает стандартный `strlen`. Мы используем его же, чтобы наша
функция была совместима по смыслу со стандартной.

`size_t` объявлен в `stdlib.h`, поэтому мы подключаем этот заголовок.
По условию нам разрешены `stdlib.h` и `stdio.h`.

## 6. Функция `s21_strlen`

> Ниже показан фрагмент `s21_string.c`. Номера строк в таблице считаются
> внутри фрагмента.

### Код

```c
/*
 * Считаем длину строки без завершающего символа '\0'.
 * Просто идём по строке, пока не встретим конец.
 */
size_t s21_strlen(const char* str) {
    size_t length = 0;

    while (str[length] != '\0') {
        length++;
    }

    return length;
}
```

### Разбор каждой строки

| Строка | Что написано | Что это значит |
|---|---|---|
| 1–5 | комментарий | Объясняет, что считаем длину без `'\0'`. |
| 6 | `size_t s21_strlen(const char* str) {` | Начало функции. Возвращает `size_t`, принимает указатель на неизменяемую строку. |
| 7 | `size_t length = 0;` | Счётчик длины. Начинаем с нуля. |
| 8 | пустая строка | Разделитель. |
| 9 | `while (str[length] != '\0') {` | Пока текущий символ не нулевой — продолжаем. `str[length]` — это символ с индексом `length`. |
| 10 | `length++;` | Увеличиваем счётчик на 1. Это то же самое, что `length = length + 1;`. |
| 11 | `}` | Конец цикла. |
| 12 | пустая строка | Разделитель. |
| 13 | `return length;` | Возвращаем количество символов до `'\0'`. |
| 14 | `}` | Конец функции. |

### Как это работает на примере `"hello"`

```text
length = 0 -> str[0] = 'h' != '\0' -> length = 1
length = 1 -> str[1] = 'e' != '\0' -> length = 2
length = 2 -> str[2] = 'l' != '\0' -> length = 3
length = 3 -> str[3] = 'l' != '\0' -> length = 4
length = 4 -> str[4] = 'o' != '\0' -> length = 5
length = 5 -> str[5] = '\0'        -> цикл заканчивается
return 5
```

### Почему нельзя просто использовать `sizeof`

`sizeof("hello")` вернёт `6`, потому что посчитает и завершающий `'\0'`.
А ещё `sizeof` работает только с массивами, размер которых известен
компилятору. Для указателя `char*` он вернёт размер указателя, а не
длину строки. Поэтому нужен цикл.

## 7. Файл `src/s21_string/s21_string_test.c`

> Здесь показан фрагмент тестового файла. Номера строк в таблице
> считаются внутри фрагмента.

### Часть для `s21_strlen`

```c
#include "s21_string.h"

#include <stdio.h>

/*
 * Печатаем результат одного теста.
 * SUCCESS — функция вернула то, что мы ожидали, FAIL — не вернула.
 */
static void print_result(int success) {
    if (success) {
        printf("SUCCESS\n");
    } else {
        printf("FAIL\n");
    }
}

/*
 * Один тест для s21_strlen.
 * input — строка, expected — ожидаемая длина.
 */
static void s21_strlen_case(const char* input, size_t expected) {
    size_t actual = s21_strlen(input);

    // Показываем вход, выход и ожидаемое значение
    printf("Input: \"%s\" | Output: %zu | Expected: %zu | ", input, actual, expected);
    print_result(actual == expected);
}

/*
 * Тесты для s21_strlen:
 * обычная строка, пустая строка (ненормальный случай),
 * строка с пробелами и строка подлиннее (краевые случаи).
 */
void s21_strlen_test(void) {
    printf("=== Testing s21_strlen ===\n");
    s21_strlen_case("hello", 5);
    s21_strlen_case("", 0);
    s21_strlen_case("a b c", 5);
    s21_strlen_case("0123456789abcdef", 16);
    printf("\n");
}
```

### Разбор каждой строки

| 4 | пустая строка | Разделитель. |
| 5–8 | комментарий | Поясняет функцию `print_result`. |
| 9 | `static void print_result(int success) {` | `static` делает функцию видимой только внутри этого файла. `success` — `1` или `0`. |
| 10 | `if (success) {` | Если `success` не ноль... |
| 11 | `printf("SUCCESS\n");` | ...печатаем `SUCCESS`. |
| 12 | `} else {` | Иначе... |
| 13 | `printf("FAIL\n");` | ...печатаем `FAIL`. |
| 14 | `}` | Конец `if`. |
| 15 | `}` | Конец функции. |
| 16 | пустая строка | Разделитель. |
| 17–20 | комментарий | Поясняет один тест длины. |
| 21 | `static void s21_strlen_case(const char* input, size_t expected) {` | Вспомогательная функция одного теста. `input` — строка, `expected` — ожидаемая длина. |
| 22 | `size_t actual = s21_strlen(input);` | Вызываем нашу функцию и сохраняем реальный результат. |

| 26 | `print_result(actual == expected);` | Сравнение даёт `1` при совпадении и `0` иначе; передаём это в `print_result`. |

| 35 | `printf("=== Testing s21_strlen ===\n");` | Заголовок группы тестов. |
| 36 | `s21_strlen_case("hello", 5);` | Обычная строка. |
| 37 | `s21_strlen_case("", 0);` | Пустая строка — ненормальный/краевой случай. |
| 38 | `s21_strlen_case("a b c", 5);` | Строка с пробелами: пробел — тоже символ. |
| 39 | `s21_strlen_case("0123456789abcdef", 16);` | Строка подлиннее, проверяем несколько разрядов. |
| 40 | `printf("\n");` | Пустая строка после группы тестов. |
| 41 | `}` | Конец `s21_strlen_test`. |

### Почему тестов минимум три

Задание требует покрыть:

- нормальные значения;
- ненормальные значения;
- краевые значения.

У нас:

1. `"hello"` — нормальное значение;
2. `""` — ненормальное/краевое;
3. `"a b c"` — пробелы внутри;
4. длинная строка — ещё один краевой случай.

### Почему `%zu`

`size_t` — беззнаковый тип. Для печати таких значений в `printf`
используется `%zu`. Если написать `%d`, поведение может быть
неправильным, особенно на 64-битных системах.

## 11. Типичные ошибки

### Забыли `'\0'`

Если строка не завершена нулём, `s21_strlen` будет читать память за
пределами массива, пока случайно не встретит ноль. Это UB.

### Использовали `sizeof` вместо длины

```c
sizeof("hello")  // 6, а не 5
```

### Неверный формат печати

```c
printf("%d", s21_strlen(str));  // неправильно для size_t
printf("%zu", s21_strlen(str)); // правильно
```

### Подключили `string.h`

По условию этого делать нельзя. Наша цель — реализовать функции
самостоятельно. В `s21_string` нет `#include <string.h>`.

### Функция `main` без `return`

В C `main` должна возвращать `int`. Лучше явно писать `return 0;`.
