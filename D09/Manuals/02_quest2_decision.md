# Quest 2. Модуль `yet_another_decision_module`

## 1. Что нужно было сделать

Нужно было доработать модуль
`src/yet_another_decision_module` так, чтобы
`yet_another_decision_module_entry.c` собирался и работал.

Главное требование:

> Функция `make_decision` должна возвращать `1`, если все данные следуют
> нормальному распределению (правилу трёх сигм) и среднее значение не
> меньше, чем обратное значение золотого сечения.

Обратное значение золотого сечения примерно равно `0.618`.

Пример:

| Вход | Выход |
|---|---|
| `4`<br>`1 2 3 4` | `YES` |

## 2. Что такое правило трёх сигм

Пусть:

- `m` — среднее арифметическое массива;
- `sigma` — стандартное отклонение;
- `max_value` — максимум;
- `min_value` — минимум.

Правило трёх сигм в нашей проверке выглядит так:

```text
max_value <= m + 3 * sigma
min_value >= m - 3 * sigma
```

То есть все числа должны лежать в интервале:

```text
[m - 3 * sigma; m + 3 * sigma]
```

Если хотя бы одно число выходит за этот интервал, функция возвращает `0`
(`NO`).

> В задании сказано, что проверка трёх сигм уже реализована в `decision.c`.
> Мы её сохранили, но переписали аккуратно и добавили необходимые
> заголовочные файлы.

## 3. Что такое дисперсия и сигма

Дисперсия — это среднее значение квадратов отклонений от среднего:

```text
variance = ((x1 - m)^2 + (x2 - m)^2 + ... + (xn - m)^2) / n
```

Стандартное отклонение — это корень из дисперсии:

```text
sigma = sqrt(variance)
```

В коде за это отвечают готовые функции `mean`, `variance` и `sqrt`.

## 7. Файл `src/yet_another_decision_module/decision.c`

```c
#include "decision.h"

#include <math.h>
#include <stdlib.h>

#include "../data_libs/data_stat.h"

/*
 * Принимаем решение по массиву.
 * Возвращаем 1 (YES), если:
 *  1) все значения попадают в правило трёх сигм;
 *  2) среднее значение не меньше GOLDEN_RATIO.
 * Иначе возвращаем 0 (NO).
 */
int make_decision(double* data, int n) {
    int decision = 0;

    if (data != NULL && n > 0) {
        double m = mean(data, n);
        double sigma = sqrt(variance(data, n));
        double max_value = max(data, n);
        double min_value = min(data, n);

        // Проверяем, что все числа лежат в интервале [m - 3*sigma; m + 3*sigma]
        int three_sigma_rule = (max_value <= m + 3 * sigma) && (min_value >= m - 3 * sigma);

        // Среднее должно быть достаточно большим
        int mean_is_good = (m >= GOLDEN_RATIO);

        decision = three_sigma_rule && mean_is_good;
    }

    return decision;
}
```

| Строка | Что написано | Что это значит |
|---|---|---|
| 1 | `#include "decision.h"` | Подключаем свой заголовок: там `GOLDEN_RATIO` и прототип. |
| 2 | пустая строка | Разделитель. |

| 15 | `int make_decision(double* data, int n) {` | Начало функции. |
| 16 | `int decision = 0;` | По умолчанию считаем, что условие не выполнено. |
| 17 | пустая строка | Разделитель. |
| 18 | `if (data != NULL && n > 0) {` | Проверяем, что массив существует и количество положительное. `&&` — логическое «и». |
| 19 | `double m = mean(data, n);` | Считаем среднее и сохраняем в `m`. |
| 20 | `double sigma = sqrt(variance(data, n));` | Считаем дисперсию, извлекаем корень — получаем стандартное отклонение. |
| 21 | `double max_value = max(data, n);` | Находим максимум. |

| 30 | `decision = three_sigma_rule && mean_is_good;` | Итог: оба условия должны быть истинны. |

### Почему `&&`, а не `&`

- `&&` — логическое «и». Результат — `0` или `1`, и вычисление идёт
  слева направо с «ленивой» проверкой.
- `&` — побитовое «и». Оно работает с битами чисел и для условий
  подходит не всегда.

В исходном коде было `decision &= ...`. Это работало, но выглядит менее
понятно. Мы заменили на обычное логическое `&&`.

### Почему `sigma` может быть равен нулю

Если все числа одинаковые, дисперсия равна нулю, и `sigma = 0`.
Тогда правило трёх сигм превращается в проверку, что все числа равны
среднему — а это как раз так. Функция не сломается: `sqrt(0) = 0`.

## 9. Почему для `1 2 3 4` получается `YES`

Посчитаем вручную:

```text
m = (1 + 2 + 3 + 4) / 4 = 2.5
```

Отклонения от среднего:

```text
1 - 2.5 = -1.5
2 - 2.5 = -0.5
3 - 2.5 =  0.5
4 - 2.5 =  1.5
```

Квадраты:

```text
2.25, 0.25, 0.25, 2.25
```

Сумма квадратов:

```text
5.0
```

Дисперсия:

```text
5.0 / 4 = 1.25
```

Сигма:

```text
sqrt(1.25) ≈ 1.118
```

Границы:

```text
m - 3 * sigma ≈ 2.5 - 3.354 = -0.854
m + 3 * sigma ≈ 2.5 + 3.354 =  5.854
```

Минимум `1` и максимум `4` попадают в интервал `[-0.854; 5.854]`.
Среднее `2.5 >= 0.618`. Значит, оба условия истинны — `YES`.

## 11. Почему нужен `-lm`

`decision.c` использует `sqrt` из `math.h`. На Linux математическая
библиотека часто не подключается автоматически, поэтому при сборке
нужно добавить `-lm` в конец команды `gcc`.

## 12. Типичные ошибки

### Забыли `#include <math.h>`

Компилятор не будет знать, что такое `sqrt`, и выдаст предупреждение
или ошибку.

### Забыли `#include "../data_libs/data_stat.h"`

Функции `mean`, `variance`, `max`, `min` не будут объявлены. В старом C
это могло «прокатить» с предупреждением, но с `-Werror` сборка упадёт.

### Перепутали `max` и `min` в правиле трёх сигм

Правильно:

```c
max_value <= m + 3 * sigma
min_value >= m - 3 * sigma
```

Если перепутать, условие будет почти всегда ложным.

### Использовали `&` вместо `&&`

Для условий лучше `&&`: код читается проще и работает по правилам
логики, а не побитовой арифметики.

### Забыли `free(data)`

Утечка памяти. Проверяется санитайзерами или valgrind.
