# Quest 1. Динамический массив и сортировка

Файл программы: `src/sort.c`.

## 1. Что требуется в задании

Нужно изменить программу сортировки массива так, чтобы память под массив
выделялась динамически с помощью `malloc` или `calloc`.

Порядок ввода:

1. сначала число `n` — количество элементов;
2. затем `n` целых чисел.

Порядок вывода:

- числа отсортированы по возрастанию;
- между числами один пробел;
- после последнего числа **нет** символа перевода строки `\n`;
- при любой ошибке нужно вывести `n/a`.

Пример:

```text
Ввод:
10
4 3 9 0 1 2 100 2 7 -1

Вывод:
-1 0 1 2 2 3 4 7 9 100
```

## 2. Полный код

```c
#include <stdio.h>
#include <stdlib.h>

int input(int** a, int* n);
void sort(int* a, int n);
void output(const int* a, int n);
void free_array(int** a);

int main(void) {
    int n = 0;
    int* a = NULL;
    int status = input(&a, &n);

    // Если ввод прошел успешно, сортируем и печатаем массив.
    if (status == 1) {
        sort(a, n);
        output(a, n);
    } else {
        // При любой ошибке показываем "n/a" без перевода строки.
        printf("n/a");
    }

    // Освобождаем память в любом случае, даже если была ошибка.
    free_array(&a);
    return 0;
}

// Читает количество элементов, выделяет память и читает сам массив.
// Возвращает 1 при успехе и 0 при ошибке.
int input(int** a, int* n) {
    int status = 1;

    if (scanf("%d", n) != 1 || *n <= 0) {
        status = 0;
    } else {
        // Выделяем память ровно под n целых чисел.
        *a = (int*)malloc((size_t)*n * sizeof(int));
        if (*a == NULL) {
            status = 0;
        } else {
            // Читаем элементы, пока не встретим ошибку.
            for (int i = 0; i < *n && status == 1; i++) {
                if (scanf("%d", &(*a)[i]) != 1) {
                    status = 0;
                }
            }
        }
    }

    // Если что-то пошло не так, память нужно освободить здесь же.
    if (status == 0) {
        free_array(a);
    }
    return status;
}

// Сортировка выбором: на каждом шаге ставим на место i минимальный элемент.
void sort(int* a, int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[i]) {
                int temp = a[i];
                a[i] = a[j];
                a[j] = temp;
            }
        }
    }
}

// Печатаем элементы через пробел. После последнего элемента нет '\n'.
void output(const int* a, int n) {
    for (int i = 0; i < n; i++) {
        if (i > 0) {
            printf(" ");
        }
        printf("%d", a[i]);
    }
}

// Безопасно освобождаем память и обнуляем указатель.
void free_array(int** a) {
    if (a != NULL && *a != NULL) {
        free(*a);
        *a = NULL;
    }
}
```

## 3. Подключение библиотек

```c
#include <stdio.h>
#include <stdlib.h>
```

- `stdio.h` нужен для `scanf` и `printf`.
- `stdlib.h` нужен для `malloc` и `free`.

Без `stdlib.h` компилятор не будет знать, что такое `malloc` и `free`.
В современном C это ошибка, особенно если включён флаг `-Werror`.

## 4. Прототипы функций

```c
int input(int** a, int* n);
void sort(int* a, int n);
void output(const int* a, int n);
void free_array(int** a);
```

Прототип — это объявление функции до её использования. Он говорит компилятору:

- как функция называется;
- какие у неё параметры;
- что она возвращает.

Разберём сигнатуры:

### `int input(int** a, int* n)`

- Возвращает `int`: `1` при успехе, `0` при ошибке.
- `int** a` — указатель на указатель. Через него функция сможет изменить
  указатель `a` в `main`.
- `int* n` — указатель на переменную `n`. Через него функция запишет
  количество элементов.

Почему не `int input(int* a, int n)`?

Потому что `a` в `main` изначально равен `NULL`. Если передать просто `a`,
функция получит копию указателя и не сможет изменить оригинал. А нам нужно,
чтобы после `input` в `main` лежал адрес выделенной памяти.

### `void sort(int* a, int n)`

- Ничего не возвращает.
- Получает уже готовый массив `a` и его размер `n`.

### `void output(const int* a, int n)`

- `const int* a` означает: функция обещает не менять элементы массива.
- Это хорошая практика: вывод не должен портить данные.

### `void free_array(int** a)`

- Получает адрес указателя, чтобы после `free` записать в него `NULL`.
- Это защищает от случайного повторного освобождения памяти.

## 5. Разбор `main`

```c
int main(void) {
    int n = 0;
    int* a = NULL;
    int status = input(&a, &n);
```

### Строка `int n = 0;`

Создаём переменную `n` — количество элементов. Пока она равна нулю.

### Строка `int* a = NULL;`

Создаём указатель `a`. Он пока никуда не указывает, поэтому равен `NULL`.
Это важно: если ввод сломается до `malloc`, `free_array` получит `NULL`
и ничего не сделает.

### Строка `int status = input(&a, &n);`

Вызываем `input`:

- передаём `&a` — адрес указателя;
- передаём `&n` — адрес переменной `n`;
- результат сохраняем в `status`.

Если `status == 1`, всё хорошо. Если `status == 0`, была ошибка.

```c
    if (status == 1) {
        sort(a, n);
        output(a, n);
    } else {
        printf("n/a");
    }
```

- Если ввод успешен, сортируем массив и выводим его.
- Иначе печатаем `n/a`.
- `printf("n/a");` не содержит `\n`, поэтому после `n/a` нет перевода строки.

```c
    free_array(&a);
    return 0;
}
```

- Освобождаем память в любом случае.
- Если память не выделялась, `free_array` спокойно ничего не сделает.
- `return 0;` — стандартное успешное завершение программы.

## 6. Разбор `input`

```c
int input(int** a, int* n) {
    int status = 1;
```

Сначала считаем, что всё хорошо: `status = 1`.

```c
    if (scanf("%d", n) != 1 || *n <= 0) {
        status = 0;
    } else {
```

- `scanf("%d", n)` читает число и записывает его по адресу `n`.
- `scanf` возвращает количество успешно прочитанных значений.
- Если вернулось не `1`, значит число не прочиталось.
- `*n <= 0` — размер должен быть положительным.
- Если ошибка, ставим `status = 0` и не идём в `else`.

```c
        *a = (int*)malloc((size_t)*n * sizeof(int));
```

Выделяем память под `n` целых чисел.

- `sizeof(int)` — сколько байт занимает одно `int`.
- `(size_t)*n` — приводим `n` к беззнаковому типу `size_t`, чтобы умножение
  не переполнилось неожиданным образом.
- `malloc` возвращает `void*`, поэтому приводим результат к `int*`.
- `*a` — это сам указатель `a` из `main`, потому что мы получили его адрес.

Пример: если `n = 10`, а `sizeof(int) = 4`, будет запрошено 40 байт.

```c
        if (*a == NULL) {
            status = 0;
        } else {
```

- Если `malloc` не смог выделить память, он вернул `NULL`.
- Это ошибка, ставим `status = 0`.
- Иначе переходим к чтению элементов.

```c
            for (int i = 0; i < *n && status == 1; i++) {
                if (scanf("%d", &(*a)[i]) != 1) {
                    status = 0;
                }
            }
```

- Цикл идёт по индексам от `0` до `n - 1`.
- Условие `status == 1` позволяет остановиться, если чтение уже сломалось.
- `(*a)[i]` — элемент массива с индексом `i`.
- `&(*a)[i]` — адрес этого элемента, потому что `scanf` нужен адрес.
- Если `scanf` не смог прочитать число, ставим `status = 0`.

Почему `(*a)[i]`, а не `*a[i]`?

Потому что `[]` имеет более высокий приоритет, чем `*`. Запись `*a[i]`
означала бы `*(a[i])`, то есть «взять `i`-й указатель и разыменовать его».
Нам нужно сначала разыменовать `a`, получить массив, а потом взять элемент.
Поэтому нужны скобки: `(*a)[i]`.

```c
    if (status == 0) {
        free_array(a);
    }
    return status;
}
```

- Если была ошибка, освобождаем память прямо здесь.
- `free_array(a)` получает `int**`, потому что `a` — это адрес указателя.
- После `free_array` указатель в `main` станет `NULL`.
- Возвращаем `status`: `1` — успех, `0` — ошибка.

## 7. Разбор `sort`

```c
void sort(int* a, int n) {
    for (int i = 0; i < n - 1; i++) {
        for (int j = i + 1; j < n; j++) {
            if (a[j] < a[i]) {
                int temp = a[i];
                a[i] = a[j];
                a[j] = temp;
            }
        }
    }
}
```

Это сортировка выбором.

Идея:

1. Берём позицию `i`.
2. Смотрим все элементы справа от неё (`j` от `i + 1` до `n - 1`).
3. Если находим элемент меньше `a[i]`, меняем их местами.
4. После внутреннего цикла на позиции `i` стоит минимальный элемент
   из оставшейся части массива.

Разбор строк:

- `for (int i = 0; i < n - 1; i++)` — внешний цикл по позициям.
  До `n - 1`, потому что последний элемент уже будет на месте.
- `for (int j = i + 1; j < n; j++)` — внутренний цикл по правой части.
- `if (a[j] < a[i])` — если справа есть элемент меньше текущего.
- `int temp = a[i];` — запоминаем текущий элемент.
- `a[i] = a[j];` — ставим на его место меньший.
- `a[j] = temp;` — возвращаем старое значение на место меньшего.

Пример:

```text
Было:  4 3 9 0
i=0:   4 сравниваем с 3, 9, 0 → 0 3 9 4
i=1:   3 сравниваем с 9, 4    → 0 3 9 4
i=2:   9 сравниваем с 4       → 0 3 4 9
```

## 8. Разбор `output`

```c
void output(const int* a, int n) {
    for (int i = 0; i < n; i++) {
        if (i > 0) {
            printf(" ");
        }
        printf("%d", a[i]);
    }
}
```

- Цикл печатает все элементы.
- Перед каждым элементом, кроме первого, печатается пробел.
- После последнего элемента пробел не печатается.
- После последнего элемента `\n` не печатается.

Получается ровно такой формат, который требует задание:

```text
-1 0 1 2 2 3 4 7 9 100
```

## 9. Разбор `free_array`

```c
void free_array(int** a) {
    if (a != NULL && *a != NULL) {
        free(*a);
        *a = NULL;
    }
}
```

- `a != NULL` — проверяем, что нам передали нормальный адрес указателя.
- `*a != NULL` — проверяем, что память действительно была выделена.
- `free(*a);` — освобождаем массив.
- `*a = NULL;` — обнуляем указатель в `main`.

Зачем обнулять?

Если случайно вызвать `free_array` второй раз, то `*a` уже будет `NULL`,
и `free` не вызовется повторно. Повторный `free` одного и того же адреса —
ошибка.

## 10. Почему память динамическая

Раньше массив был фиксированного размера:

```c
int data[10];
```

Это значит, что максимум можно было ввести 10 чисел.

Теперь размер известен только во время выполнения программы:

```c
int* a = malloc(n * sizeof(int));
```

Если пользователь введёт `n = 1000`, программа выделит память под 1000 чисел.
Если `n = 3`, выделит только под 3.

## 11. Ошибки и `n/a`

Программа выводит `n/a`, если:

- `n` не число;
- `n <= 0`;
- `malloc` не смог выделить память;
- хотя бы один элемент массива не является числом.

При этом память освобождается, чтобы не было утечек.

## 12. Компиляция и запуск

```sh
gcc -std=c11 -Wall -Wextra -Werror -pedantic src/sort.c -o sort
printf '10\n4 3 9 0 1 2 100 2 7 -1' | ./sort
```

Ожидаемый вывод:

```text
-1 0 1 2 2 3 4 7 9 100
```

## 13. Частые ошибки

1. **Забыть `free`.** Память останется занятой после завершения программы.
2. **Использовать `a[i]` вместо `(*a)[i]`.** В функции с `int**` это ошибка.
3. **Не проверить `malloc`.** Если памяти нет, программа упадёт.
4. **Не проверить `scanf`.** Тогда в массиве окажутся случайные значения.
5. **Печатать `\n` в конце.** Автотест может не принять вывод.
6. **Печатать пробел после последнего числа.** Задание требует формат без
   лишнего пробела в конце.
7. **Забыть освободить память при ошибке ввода.** Это утечка.
