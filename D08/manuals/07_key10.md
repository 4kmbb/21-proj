# Quest 7. Ключ `key10.txt`

Файл с ответом: `src/key10.txt`.

## 1. Условие задания

В конце Quest 7 дана запись:

```text
       1 T       87  46  57  29
       2    *   129 156 122 141
       3        143 127 107 116
       4         69  78 112 101
```

Нужно вычислить результат и сохранить его в `src/key10.txt`.

## 2. Как читать запись

Слева стоит столбец:

```text
1
2
3
4
```

Это вектор-столбец:

```text
    | 1 |
v = | 2 |
    | 3 |
    | 4 |
```

Рядом стоит буква `T`. Она означает транспонирование. Транспонирование
превращает вектор-столбец в вектор-строку:

```text
v^T = [ 1  2  3  4 ]
```

Дальше стоит знак умножения `*` и матрица `4 x 4`:

```text
    |  87   46   57   29 |
A = | 129  156  122  141 |
    | 143  127  107  116 |
    |  69   78  112  101 |
```

Получается выражение:

```text
v^T * A
```

Размеры:

```text
(1 x 4) * (4 x 4) = (1 x 4)
```

То есть результатом будет вектор-строка из четырёх чисел.

## 3. Правило умножения матриц

Если `C = A * B`, то элемент `C[i][j]` считается так:

```text
C[i][j] = сумма A[i][k] * B[k][j] по всем k
```

В нашем случае `A` — это вектор-строка `v^T`, у него одна строка `i = 0`.
Поэтому результат тоже имеет одну строку.

Каждый элемент результата — это скалярное произведение вектора `v^T` на
соответствующий столбец матрицы `A`.

```text
result[0][j] = 1*A[0][j] + 2*A[1][j] + 3*A[2][j] + 4*A[3][j]
```

## 4. Вычисление по столбцам

### Первый столбец

Столбец:

```text
 87
129
143
 69
```

Считаем:

```text
1*87 + 2*129 + 3*143 + 4*69
= 87 + 258 + 429 + 276
= 1050
```

Первое число результата: `1050`.

### Второй столбец

Столбец:

```text
 46
156
127
 78
```

Считаем:

```text
1*46 + 2*156 + 3*127 + 4*78
= 46 + 312 + 381 + 312
= 1051
```

Второе число результата: `1051`.

### Третий столбец

Столбец:

```text
 57
122
107
112
```

Считаем:

```text
1*57 + 2*122 + 3*107 + 4*112
= 57 + 244 + 321 + 448
= 1070
```

Третье число результата: `1070`.

### Четвёртый столбец

Столбец:

```text

141
116
101
```

Считаем:

```text

= 29 + 282 + 348 + 404
= 1063
```

Четвёртое число результата: `1063`.

## 5. Итог

## 7. Почему `T` стоит именно у вектора

Если бы `T` не было, выражение было бы:

```text
v * A
```

где `v` — столбец `4 x 1`. Умножать `(4 x 1)` на `(4 x 4)` нельзя: число
столбцов первой матрицы (`1`) не равно числу строк второй (`4`).

После транспонирования:

```text
v^T — это (1 x 4)
A   — это (4 x 4)
```

Число столбцов `v^T` равно `4`, число строк `A` равно `4`, поэтому умножение
возможно.

## 8. Частая ошибка

Иногда результат пытаются получить как `A * v`, то есть матрицу умножить на
вектор-столбец:

```text
A * v
```

Это тоже возможно по размерам:

```text
(4 x 4) * (4 x 1) = (4 x 1)
```

Но это **другое** выражение. В задании написано `v^T * A`, поэтому ответ
должен быть вектором-строкой:

```text
1050 1051 1070 1063
```

а не вектором-столбцом.
