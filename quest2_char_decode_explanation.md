# Объяснение решения задания 2 (`src/char_decode.c`)

## Что делает программа
Программа работает в двух режимах, которые задаются аргументом командной строки:
- `0` — кодирование символов в HEX;
- `1` — декодирование HEX в символы.

При ошибке выводится `n/a`.

## Основные функции

### 1. `encode_symbol(char symbol)`
Преобразует символ в его числовой ASCII-код.

### 2. `decode_symbol(int value)`
Преобразует числовой код обратно в символ.

### 3. `hex_digit_to_int(char symbol)`
Преобразует один шестнадцатеричный символ (`0..9`, `A..F`, `a..f`) в число от `0` до `15`.
Если символ не HEX, возвращает `-1`.

### 4. `decode_hex_pair(char first, char second, int *ok)`
Преобразует пару HEX-символов в одно число байта (`00..FF`):
- сначала каждый символ переводится в число;
- затем считается `value1 * 16 + value2`.
Если хотя бы один символ невалидный, флаг `ok` переводится в `0`.

## Режим кодирования: `process_encode_mode()`
Ожидается ввод вида: `W O R L D`.

Логика:
- чтение идет посимвольно до `\n`;
- каждый токен между пробелами должен иметь длину ровно `1` символ;
- каждый символ печатается как двухзначный HEX через `%02X`;
- между результатами ставится пробел.

Если найден токен длиной не `1` (например, `WORLD`), это ошибка и возвращается `ok = 0`.

## Режим декодирования: `process_decode_mode()`
Ожидается ввод вида: `48 45 4C 4C 4F`.

Логика:
- чтение идет посимвольно до `\n`;
- каждый токен между пробелами должен иметь длину ровно `2`;
- пара HEX-символов декодируется в один символ;
- символы выводятся через пробел.

Если токен не из двух символов или содержит не HEX-символы, это ошибка.

## `main(int argc, char *argv[])`
Главная функция:
- проверяет, что передан ровно один аргумент режима;
- запускает `process_encode_mode()` для `0`;
- запускает `process_decode_mode()` для `1`;
- для всех остальных случаев печатает `n/a`.

## Почему такая проверка ввода
Проверка сделана строго по условиям задачи:
- кодирование: только отдельные символы через пробел;
- декодирование: только пары HEX через пробел;
- любой другой формат считается ошибочным.
